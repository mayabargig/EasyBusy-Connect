# EasyBusy Connect - רשימת בדיקה להגנה

## מספר ימים לפני ההגנה

- לוודא שגרסת Node.js היא 18.18 ומעלה.
- לבצע `npm install` במחשב שבו תוצג המערכת.
- לוודא שקובץ `server/.env` קיים ושאינו נמצא ב-GitHub.
- להפעיל `npm run check` ולוודא שאין שגיאות.
- לוודא שה-IP הנוכחי מורשה ב-MongoDB Atlas.
- להכין נקודת גישה חלופית לאינטרנט במקרה הצורך.
- להוריד עותק של ZIP ההגשה ולבדוק דווקא אותו בתיקייה חדשה.

## הכנת נתוני הדגמה

- לקבוע `ALLOW_DEMO_SEED=true` וסיסמה פרטית ב-`server/.env`.
- להריץ `npm run seed` פעם אחת.
- להחזיר `ALLOW_DEMO_SEED=false`.
- לשמור לעצמך את כתובות ה-Demo והסיסמה, בלי להוסיף אותן ל-Git.

## בדיקת לקוחה

- להתחבר כחשבון הלקוחה.
- לחפש עסק לפי מילת חיפוש, עיר וקטגוריה.
- לפתוח פרופיל עסק ולהזמין שירות.
- לחפש פוסטים לפי מילת חיפוש, קטגוריה וטווח תאריכים.
- ליצור, לערוך ולמחוק פוסט של הלקוחה.
- לערוך או לבטל תור מתאים.
- לשלוח, לחפש, לערוך ולמחוק הודעה בצ'אט.
- לפתוח את עמוד הסטטיסטיקה ולהחליף בין 3, 6 ו-12 חודשים.

## בדיקת בעלת עסק

- להתנתק ולהתחבר כבעלת עסק.
- לוודא שלא מתבצעת בקשת שיחה של החשבון הקודם.
- לערוך פרטי עסק ולהוסיף או לערוך שירות.
- לחפש עסקים ופוסטים.
- ליצור, לערוך ולמחוק פוסט.
- לאשר, לדחות, להשלים או לבטל תור בהתאם למצבו.
- לנהל שיחה עם לקוחה ולבדוק עדכון בזמן אמת בשני חלונות.
- לפתוח את גרפי הסטטיסטיקה העסקיים.

## דרישות טכנולוגיות להראות למרצה

- Node.js ו-Express בצד השרת.
- MongoDB וארבעת מודלי Mongoose.
- הפרדת Models, Controllers, Routes ו-Views.
- CRUD וחיפוש דרך הממשק.
- React, רכיב Video ורכיב Canvas.
- `$.ajax` בשירות `client/src/services/api.js`.
- שימוש jQuery מבוקר ב-`useJQueryReveal`.
- חמש יכולות CSS3 ב-`client/src/styles.css`.
- Socket.io בצ'אט.
- שני גרפי D3 עם נתונים דינמיים מ-MongoDB.

## רגע לפני ההגשה

- `git status` מציג `working tree clean`.
- כל ה-commits וה-tag האחרון מופיעים ב-GitHub.
- ה-Repository ציבורי לצפייה.
- ה-ZIP אינו כולל `.env`, `node_modules`, `dist` או `.git`.
- קישור GitHub נוסף בהערת ההגשה במודל.
- ה-ZIP שהוגש זהה לגרסה שתופעל בהגנה.
