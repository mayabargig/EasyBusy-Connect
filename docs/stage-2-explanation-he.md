# הסבר שלב 2 פרופיל משתמש וספריית עסקים

## מה נוסף בשלב הזה

בשלב 2 הושלמו כל הפעולות הנדרשות עבור מודל `User`:

- Create מתבצע במסך ההרשמה.
- Update מתבצע במסך My profile.
- Delete מתבצע במסך My profile לאחר אימות הסיסמה.
- List מתבצע במסך Discover.
- Search מתבצע במסך Discover לפי מילת חיפוש עיר וקטגוריה.

בעל עסק הוא עדיין משתמש במערכת ולכן פרטי העסק נשמרים כתת מסמך בשם
`businessProfile` בתוך מודל המשתמש. כך אין כפילות של שם אימייל עיר והרשאות
בין שני מודלים נפרדים.

## זרימת בקשה במבנה MVC

לדוגמה כאשר משתמשת שומרת את הפרופיל:

1. הקומפוננטה `ProfilePage` אוספת את הנתונים מהטופס.
2. `AuthContext` שולח בקשת `PATCH` לכתובת `/api/users/me`.
3. ה interceptor בקובץ `api.js` מוסיף לבקשה את ה JWT.
4. `requireAuth` בודק את הטוקן וטוען את המשתמש ממסד הנתונים.
5. `user.routes.js` מפעיל ולידציות על כל שדה.
6. `user.controller.js` מעדכן רק את המשתמש המחובר.
7. `User.js` מפעיל את חוקי הסכמה ושומר ב MongoDB.
8. השרת מחזיר את המשתמש המעודכן וה React מציג את הנתונים החדשים.

## קבצי השרת

### models User.js

מגדיר את מבנה המשתמש ואת פרטי העסק והשירותים. לכל שירות יש שם תיאור משך
ומחיר. המתודה `toPublicJSON` מיועדת למשתמש שמחובר לחשבון שלו וכוללת אימייל.
המתודה `toDirectoryJSON` מיועדת למשתמשים אחרים ולכן אינה חושפת אימייל או
סיסמה.

בטופס ניתן להזין את משך השירות בדקות או בשעות. לפני שליחת הנתונים לשרת
הלקוח ממיר שעות לדקות והמסד שומר תמיד `durationMinutes`. שמירה ביחידה אחידה
מקלה בהמשך על חיפוש תורים חישוב זמינות ומיון שירותים. בתצוגה הערך מומר בחזרה
לטקסט קריא כמו `3 hours` או `1 hr 30 min`.

### routes user.routes.js

מגדיר את כתובות ה API ואת כללי הולידציה. הנתיבים נמצאים אחרי `requireAuth`
ולכן רק משתמש מחובר יכול להשתמש בהם.

### controllers user.controller.js

מכיל את הלוגיקה של רשימה חיפוש צפייה עדכון ומחיקה. החיפוש בונה מסנן MongoDB
לפי הפרמטרים שהלקוח שלח. המחיקה טוענת זמנית גם את הסיסמה המוצפנת ומשווה אותה
לסיסמה שהוזנה באמצעות bcrypt.

## קבצי הלקוח

### ProfilePage.jsx

טופס לעריכת משתמש. לבעל עסק מוצגים גם שדות העסק ורשימת שירותים דינמית.
השירותים נמצאים במערך ולכן אפשר להוסיף להסיר ולעדכן כל שירות בנפרד.

### DiscoverPage.jsx

מציג את רשימת בעלי העסקים. הטופס כולל שלושה פרמטרים שהמשתמש יכול להגדיר:
מילת חיפוש עיר וקטגוריה. הנתונים מגיעים מהשרת ומ MongoDB ואינם רשימה קבועה
בקוד.

### UserDetailsPage.jsx

מציג פרופיל ציבורי של עסק ואת השירותים שלו. האימייל של בעל העסק אינו נשלח
למסך הזה מטעמי פרטיות.

## בדיקה ידנית מומלצת

1. להפעיל `npm run dev`.
2. להתחבר כבעלת עסק.
3. להיכנס ל My profile ולהשלים שם עסק קטגוריה ותיאור.
4. להוסיף שני שירותים ולשמור.
5. להיכנס ל Discover ולחפש לפי שלושת הפרמטרים.
6. לפתוח את כרטיס העסק ולוודא שהשירותים מוצגים.
7. לעדכן פרט בפרופיל ולוודא שהשינוי מופיע גם ב MongoDB Atlas.

אין צורך לבדוק מחיקת חשבון עם המשתמש הראשי. אם רוצים להדגים Delete עדיף
ליצור משתמש בדיקה נפרד ולמחוק אותו.
