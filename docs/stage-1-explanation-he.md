# הסבר שלב 1 — הרשמה והתחברות

## מה קורה בהרשמה?

1. המשתמשת ממלאת טופס ב־React.
2. הקליינט שולח בקשת `POST /api/auth/register`.
3. השרת בודק שכל השדות תקינים.
4. השרת בודק שלא קיים משתמש עם אותו אימייל.
5. מודל `User` מצפין את הסיסמה לפני השמירה.
6. MongoDB שומר את המשתמש.
7. השרת יוצר JWT ומחזיר אותו יחד עם פרטי משתמש בטוחים.
8. הקליינט שומר את הטוקן ומציג את ה־Dashboard.

## מה קורה בהתחברות?

1. הקליינט שולח אימייל וסיסמה ל־`POST /api/auth/login`.
2. השרת מחפש את המשתמש לפי אימייל.
3. bcrypt משווה בין הסיסמה שנשלחה לבין הסיסמה המוצפנת.
4. במקרה של התאמה השרת מחזיר JWT חדש.

## למה צריך Middleware?

ה־Middleware בשם `requireAuth` רץ לפני Controller מוגן. הוא מוציא את הטוקן מכותרת `Authorization`, מאמת אותו וטוען את המשתמש ממסד הנתונים. רק לאחר מכן הבקשה ממשיכה ל־Controller.

## למה לא שומרים סיסמאות בקוד?

פרטים משתנים ורגישים נשמרים בקובץ `.env`, שאינו עולה ל־GitHub. בפרויקט קיים רק `.env.example` עם שמות המשתנים ודוגמאות שאינן סודיות.
