# הסבר שלב 3 פוסטים ופיד חברתי

## מה נוסף בשלב הזה

בשלב 3 נוסף המודל השני בפרויקט בשם `Post`. לכל פוסט יש מחבר תוכן קטגוריה
וסוג מדיה אופציונלי. כל פעולות ה CRUD זמינות דרך הממשק:

- Create באמצעות הטופס New post.
- Update באמצעות הכפתור Edit בפוסט של המשתמש המחובר.
- Delete באמצעות הכפתור Delete בפוסט של המשתמש המחובר.
- List באמצעות הפיד שמציג את הפוסטים מהחדש לישן.
- Search לפי מילת מפתח קטגוריה תאריך התחלה ותאריך סיום.

החיפוש הזה הוא החיפוש המתקדם השני בפרויקט. הראשון הוא חיפוש העסקים לפי מילת
חיפוש עיר וקטגוריה.

## מבנה השרת

### models Post.js

הסכמה מגדירה את השדות הבאים:

- `author` הוא ObjectId שמפנה למודל User.
- `content` הוא תוכן הפוסט עד 1200 תווים.
- `category` מגדירה את סוג הפוסט.
- `mediaType` יכול להיות none image או video.
- `mediaUrl` מכיל כתובת ציבורית לתמונה או לסרטון.

### routes post.routes.js

כל הנתיבים מוגנים באמצעות `requireAuth`. הנתיבים בודקים את תוכן הפוסט סוג
המדיה כתובת המדיה ופרמטרי החיפוש לפני שהם מגיעים ל controller.

### controllers post.controller.js

ה controller מבצע את פעולות מסד הנתונים. לפני עריכה או מחיקה הוא משווה את
מזהה מחבר הפוסט למזהה המשתמש המחובר. גם אם מישהו מנסה לשלוח בקשת API ידנית
השרת מחזיר 403 ולא מאפשר לשנות פוסט של משתמש אחר.

בשליפת הפיד נעשה שימוש ב `populate` כדי להחליף את מזהה המחבר בפרטים ציבוריים
כמו שם תמונת פרופיל ושם העסק. אימייל וסיסמה אינם נשלחים.

## מבנה הלקוח

### PostsPage.jsx

המסך כולל שלושה אזורים:

1. טופס יצירת פוסט.
2. טופס חיפוש עם ארבעה פרמטרים.
3. רשימת פוסטים עם אפשרות עריכה ומחיקה לבעלת הפוסט בלבד.

הקומפוננטה `PostMedia` בודקת את `mediaType`. תמונה מוצגת באמצעות `img` וסרטון
מוצג באמצעות רכיב `video` של React עם controls. בכך מתקיימת דרישת ה Video
של המטלה.

## בדיקה ידנית מומלצת

1. להתחבר באמצעות החשבון העסקי ולפרסם פוסט טקסט.
2. לפרסם פוסט נוסף עם תמונה או סרטון מכתובת ציבורית ישירה.
3. לערוך את הפוסט ולוודא שהשינוי מופיע מיד וב MongoDB Atlas.
4. להתחבר באמצעות חשבון הלקוחה ולוודא שאין כפתורי עריכה לפוסט העסקי.
5. לפרסם פוסט מהלקוחה ולבדוק שרק היא יכולה לערוך אותו.
6. לחפש לפי קטגוריה מילת מפתח וטווח תאריכים.
7. למחוק משתמש בדיקה בלבד ולוודא שגם הפוסטים שלו הוסרו.
